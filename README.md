# Wordpress-Plugins
Custom WordPress plugins. One folder per plugin, each with its own README and release ZIP.

| Plugin | Version | Get it | What it does |
|---|---|---|---|
| [Quiet Update Emails](quiet-update-emails) | 3.0.1 | [WordPress.org](https://wordpress.org/plugins/quiet-update-emails/) or [ZIP](quiet-update-emails/quiet-update-emails.zip) | Silences routine automatic update emails, keeps the failure alerts, and logs every core, plugin and theme update. Has a settings screen, recipient override, subject tags, Site Health entry and multisite support. |

**Quiet Update Emails is in the WordPress.org plugin directory:** [wordpress.org/plugins/quiet-update-emails](https://wordpress.org/plugins/quiet-update-emails/). The easiest way to install it is from inside WordPress: go to **Plugins → Add Plugin**, search for "Quiet Update Emails", then **Install Now** and **Activate**. Updates then arrive through the normal WordPress update screen. The ZIP in this repository is the same release, for installing by upload. Full instructions are in the [plugin's README](quiet-update-emails/README.md#installation).

**Quiet Update Emails is the successor to Disable Auto-Update Success Emails**, which has been removed from this repository. Its last version, 2.1, is still available [in the repository history](https://github.com/Advanced-Micro-Technologies/Wordpress-Plugins/tree/eda95e306c6c733d480010a2ba6df418b8911fd8/disable_update_emails). Sites that still run it should [move to Quiet Update Emails](quiet-update-emails/README.md#moving-a-site-from-disable-auto-update-success-emails).
